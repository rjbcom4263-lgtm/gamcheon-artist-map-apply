# 감천문화마을 3D 작가 지도

## 문화마을 확장

사용자 요청에 따라 기존 형식을 유지하며 문화마을 주요 관광 구역과 연결 골목으로 확대했습니다. 작업 경계는 서 129.006 / 남 35.09274 / 동 129.0135 / 북 35.0992입니다. 공식 행정·특별관리지역 경계가 아니며 주변 일부 건물을 포함합니다. 주요 시설 맥락은 [문화마을 공식 안내](https://www.gamcheon.or.kr/gamcheon/page/user/intro2)를 참고했으나, 공식 경계 데이터는 확보하지 못했습니다.

- 기존 487개 건물을 모두 포함하고 원본 ID와 좌표를 보존합니다. 기존 외관 보정 저장 키도 유지합니다.
- 어린왕자상은 확보된 OSM 원본 `node/10679830337` 좌표로 추가했습니다.
- 3D와 항공 지도, GPS 범위 판정, 검색과 건물 목록이 같은 확대 범위를 사용합니다.
- 넓어진 지형에 맞춰 카메라가 전체 3D 경계 상자를 계산하여 화면을 맞춥니다. 가로·세로 화면 및 위에서 보기 모드를 좌표 투영 검사로 검증합니다.
- 전체 보기에서는 작은 지붕 테두리를 숨기고, 지붕색을 적용할 때 도형을 다시 생성하지 않습니다. 그림자는 건물 변경 때만 갱신합니다. 실제 모바일 프레임률은 미측정입니다.
- 기존 임시 외관·지붕색 추정·지형 정확도 제한은 그대로 적용됩니다. 아래 1차 구역 기록은 제작 이력입니다.

## 2026-09-09 · 사용자 지정 구간

기본 화면은 `Village3DView`의 회전 가능한 Three.js 3D 시안이며, 상단에서 기존 항공 지도로 전환합니다. 선택한 건물과 작가 초안은 두 화면이 공유합니다.

- 사용자 확정 범위: 방가방가 게스트하우스 부근부터 감천마을 공영주차장 부근까지 제공 캡처 전체.
- 작업 경계: 서 129.00853 / 남 35.09274 / 동 129.01053 / 북 35.09745. 145×511 캡처와 두 기준 위치를 대조한 **근사치**이며, 정확한 좌우 경계·필지 범위는 원본 지도 링크와 추가 대조가 필요합니다.
- 북측 기준 좌표: https://triple.guide/hotels/6f1917be-c7e9-498b-86f3-4bf05fbabc59 에 공개된 129.009552, 35.097181.
- 남측 대조 좌표: https://cmap.or.kr/page.php?cno=31 지도에 공개된 감천제일교회 좌표 129.00915516545504, 35.09397150178058.
- 공영주차장 라벨 좌표는 캡처상의 상대 위치로 추정했으며, 정확한 출입구가 아닙니다. 화면에도 위치 대조 필요로 표시합니다.
- `village.ts`에서 원본 건물 윤곽을 그대로 필터링하고 도로는 경계에서 선분 단위로 자릅니다. 부분적으로 경계에 걸친 건물은 분리하지 않고 전체 오브젝트로 보존합니다. 실제 현장 전체 건물 수를 보장하지 않습니다.
- 3D는 실측 외관 복원 완료본이 아닙니다. 미등록 건물 높이는 **표현용 6m**, 평지붕과 외벽은 임시 표현입니다. 원본 OSM의 `height: null`은 보존합니다. 실제 지붕 형태, 층수, 벽화, 창문, 옹벽, 개별 계단 높이는 확보되지 않았습니다.
- 지붕색은 Esri 항공사진의 건물 중심 5×5 픽셀 중앙값을 밝게 정돈한 추정색입니다. 촬영각도, 시기, 가림, 오차 때문에 다른 물체의 색이 포함될 수 있으며 외벽색의 근거가 아닙니다. 사진 다운로드 파일이나 타일 캐시는 생성하지 않습니다.
- 약 30m급 Mapterhorn 고도를 보간해 지형과 건물을 배치합니다. 경사면 위 기초는 모델이 지형에 잠기지 않게 하는 시안 구조이며 실제 옹벽을 뜻하지 않습니다. 지형 연결 실패 시 평지 시안임을 명시합니다.
- 건물 선택 → 외관 보정: 높이, 외벽색, 지붕색, 참고용 창문을 조정합니다. 창문은 기본 꺼짐이며 실제 위치가 아닌 반복 표현입니다. 보정은 이 브라우저의 `gamcheon-area1-appearance-v1` 키에 저장하고 JSON으로 내려받을 수 있습니다. 실제 확인 완료 상태로 바꾸거나 공개 DB에 쓰지 않습니다.
- GPS는 버튼을 누를 때만 요청하며 구역 밖이면 안내합니다. 위치 오차 원은 화면 표현이며 현장 위치·보행 길찾기를 보증하지 않습니다.
- 렌더링은 시점/자료 변화 시에만 실행하고 픽셀 비율을 제한합니다. 실기기 프레임률과 터치 사용성은 별도 확인이 필요합니다.
- WebMCP의 `select_gamcheon_building`은 지원 브라우저에서 건물 선택만 수행합니다. 이 실행 환경에서는 지원되는 WebMCP 검증 컨텍스트가 없어 실제 등록·호출을 검증하지 못했습니다.

검증: `node --test tests/village-3d.test.mjs tests/gps-map.test.mjs`는 범위 자르기, 원본 보존, GPS 왕복 변환, 모든 건물의 유한 3D 정점과 높이, 지형 raycast, 작가 연결을 검사합니다. 전체 프로젝트 타입 검사에는 기존 관리자/신청 페이지의 오류가 남아 있으므로 지도 변경 파일을 별도로 검사합니다. 공개 서비스는 기존 공개 범위이므로 이 시안을 자동 배포하지 않습니다.

아래는 기존 항공 지도 화면 및 원본 스냅샷에 대한 기록입니다.

`/`와 `/map`은 GpsArtistMap을 표시합니다. 종전 일러스트 시안과 이미지는 별도 파일로 보존했으며 현재 지도에 가상의 작가·위치는 표시하지 않습니다.

## 범위와 출처

- 조회 경계: 서 129.004 / 남 35.092 / 동 129.015 / 북 35.101. 감천문화마을과 주변 조회 범위이며 감천2동 행정경계나 전체 마을을 의미하지 않습니다.
- OSM 원본 스냅샷: `public/map-data/osm-source.json`. https://overpass.private.coffee/api/interpreter 에서 한 번 조회했습니다. 방문자 브라우저는 Overpass를 호출하지 않습니다.
- 추출 데이터: `public/map-data/gamcheon.geojson`, 건물 1,945개, 도로·보행 선 372개(이 중 계단 14구간), 장소 23개, 출입구 점 4개. 조회된 공개 정보 개수이며 현장 전체 개수가 아닙니다.
- OSM 데이터는 © OpenStreetMap contributors, ODbL 1.0: https://www.openstreetmap.org/copyright . 가공된 GeoJSON 및 원본을 같이 제공합니다.
- 배경: OpenFreeMap Positron / OpenMapTiles / OSM. https://openfreemap.org/quick_start/ . 배경 연결 실패 시 지역 건물·도로 레이어를 표시합니다.
- 3D 지형: Mapterhorn https://tiles.mapterhorn.com/tilejson.json / https://mapterhorn.com/attribution . 한국은 약 30m급 전역 자료로, 계단·출입구 높이를 판별하는 용도가 아닙니다.
- 기본 배경은 Esri World Imagery 항공·위성사진입니다. https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer . 서비스 제공 출처: Esri, Vantor, Earthstar Geographics, GIS User Community. 출처는 지도에 표시하며 타일은 브라우저에서 직접 요청합니다. 일반 지도와 전환할 수 있습니다. 항공사진은 3D 건물 모델이 아니며 촬영 시점·촬영 각도·정사보정 차이로 OSM 윤곽과 어긋날 수 있습니다. 사진을 근거로 건물 윤곽을 자동 변경하지 않습니다.
- 높이 미등록 건물의 6m 일괄 블록 표현을 제거했습니다. 층수만 있는 건물도 높이는 `null`로 유지합니다. 현재 스냅샷에 명시적인 높이는 0개, 층수는 8개입니다. 실제 높이 필드가 있는 건물만 지형 보기에서 입체화하며 현재 건물들은 지면 위 윤곽으로 표시됩니다.
- 항공사진에서는 평상시 건물 채움을 거의 투명하게 하고, 확대할수록 얇은 경계선을 표시합니다. 마우스로 가리키거나 선택한 건물만 강조합니다. 일반 지도에서는 밝은 건물 면과 경계를 표시합니다. 지도 기울기는 40도로 제한해 불필요한 가림을 줄입니다.

## 사용

1. 지도에서 실제 건물을 선택하거나 건물 목록으로 검색합니다.
2. 상세 카드에서 작가 표시를 연결합니다. 이름, 분야, 작업실, 층·호수와 메모를 입력합니다.
3. 출입구는 지도에서 별도로 찍습니다. 실측 여부는 확인하지 않으므로 지정한 좌표는 항상 초안입니다.
4. 초안은 화면 메모리에만 존재합니다. 새로고침하면 없어지며 **초안 내려받기**로 JSON을 저장할 수 있습니다. 공개 작가 DB에는 쓰지 않습니다.
5. 같은 건물에 여러 작가를 연결하면 하나의 건물 핀으로 묶습니다. 멀리 보면 주변 작가 핀이 군집화됩니다.
6. ‘내 위치’를 누를 때만 Geolocation 권한을 요청합니다. 현재 위치와 정확도 원을 표시합니다. 우리 서버에 위치를 전송·저장하지 않습니다. HTTPS 또는 localhost가 필요합니다. 위치를 보는 지도 타일 요청은 외부 지도 서비스로 전달됩니다.

건물 표시 중심은 출입구가 아닙니다. 보행 길찾기, 소요시간, 통행 가능 여부, 계단 수, 작가 영업 상태는 아직 제공하지 않습니다. 실제 운영 전에는 작가 동의·정확한 건물 연결·출입구·골목을 현장 확인하고 승인된 데이터만 게시해야 합니다. 지도 비콘은 화면 표시이며 Bluetooth 비콘이 아닙니다.

## 검증과 개발

- `node --test tests/gps-map.test.mjs` : 실제 윤곽·고유 ID·좌표, 초안 연결과 출입구 유효성, 건물별 작가 그룹 검증.
- `node scripts/prepare-gamcheon-map.mjs` : 확보된 원본 스냅샷을 가공. 건물 관계형 도형이 생기면 조용히 누락하지 않고 실패시킵니다.
- Windows 미리보기: `node_modules/.bin/vite.cmd --host 127.0.0.1 --port 5173 --strictPort`.
- Windows 빌드: `node_modules/.bin/vinext.cmd build` (기존 Linux 래퍼가 호출하는 실제 빌드 명령).
- MapLibre는 클라이언트에서만 로드합니다. Vite의 `?worker&url`을 사용해 6.x 모듈 워커와 내부 의존성을 함께 번들링합니다.
- 새 지도 파일은 별도 엄격 타입 검사를 통과해야 합니다. 기존 관리자·신청 영역의 전체 프로젝트 타입 오류는 이번 변경 범위에 포함하지 않습니다.

MapLibre 지도 엔진은 외부 타일·폰트·고도 연결과 WebGL을 필요로 합니다. 실제 휴대폰의 GPS 정확도 및 현장 길 접근성은 아직 검증하지 않았습니다.
